# Advanced School Management System

An academic Laravel-based school administration project, preserving the original application source and documenting its modules, architecture, and setup requirements.

**Status:** Source-code archival and documentation in progress. The application has not been runtime-verified.

## Technology

PHP, Laravel 8, Blade templates, Bootstrap, JavaScript, and MySQL configuration.

## Modules represented in the source

Student records, classes, sections, subjects, timetables, user accounts, and role-based administration. Other routes refer to modules whose implementation is incomplete in the available source.

## Security and setup

Never commit a real `.env` file or credentials. Use a local environment file, install dependencies using Composer, and supply a database schema before attempting to run the application.
